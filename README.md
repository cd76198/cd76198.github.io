# 신진섭 레벨디자인 포트폴리오

공개 사이트: https://cd76198.github.io/

## 구성

- 지령서 도입 화면과 원문 임무 내용
- UE5에서 내보낸 외부 필드 `던전외부필드_v09-17_A` 및 보수 던전 `던전내부최종_보수_v02` 탐색
- 고정 쿼터뷰 이동, 다리 파괴·복구, 추격자와 중간보스, 문 개방, 계단 차단막, 색 순서 장치, 페널티와 종료 상태의 웹 재구성
- 번호 표시가 있는 필드 지점에 접근하면 나타나는 기획 문구, 플레이 없이 열 수 있는 필드 설명 팝업, 필드·던전 번호 설명을 클릭해 확대할 수 있는 자유 회전 3D 뷰어
- 프로젝트 소개 카드와 참고 영상

로컬 실행: 저장소 루트에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속합니다. `file://`로 열면 모듈과 GLB를 불러올 수 없습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W A S D | 이동 (UE +X / ±Y 축 대응) |
| J 또는 화면 클릭 | 공격 |
| E | 상호작용, 문 앞에서 계속 누르면 개방 |
| R | 현재 맵 처음부터 |
| 화면 아래 터치 버튼 | 모바일 이동·공격·상호작용 |

## 자료와 차이

`assets/models/`에는 시각 모델과 충돌 모델을 각각 보존합니다. `assets/data/play-map.json`에는 원본 위치, 카메라 오프셋, 상호작용 오브젝트를 간추렸습니다. 모델과 규칙은 사용자가 전달한 UE5 `web-export.zip`을 바탕으로 통합했습니다. Three.js 0.180.0은 `vendor/`에 포함되며 MIT 라이선스는 `vendor/LICENSE-three.txt`를 참조합니다.

필드의 원본 OpenLevel 목적지는 보수 이전 던전이고, 웹은 전달받은 최신 보수 v02로 전환합니다. 웹의 보행·충돌·AI·전투·시각 효과는 UE 런타임과 완전히 동일하지 않습니다. 보행은 원본 충돌 삼각형에 대한 캡슐 이동·계단 오르기·접지 판정을 사용합니다(반지름 35cm, 반높이 90cm, 최대 턱 45cm, 보행 법선 Y ≥ 0.710000038). 브라우저용 근사 구현이므로 UE 엔진 자체와의 완전한 동작 일치를 의미하지 않습니다. WebGL을 사용할 수 없는 환경에서는 접힌 「플레이 없이 필드 내용 보기」에서 설명 팝업을 열 수 있습니다.

프로필·프로젝트 소개는 `js/site-data.js`에서, 웹 플레이 규칙은 `js/play.js`에서 관리합니다. PDF, 이력서, 연락처는 제공되면 해당 링크를 추가할 수 있습니다.

필드 번호 지점의 문장은 Google Drive 최종 제출 PDF 「01_안게모스의_순례길_필드_레벨기획서_신진섭.pdf」 7~14·17~23쪽에서 발췌했습니다. 필드 번호는 시작 → 바닥타일 → 호수 → 천막 → 순례자의 계단 → 차단된 옛 길 → 틈으로 보는 힌트 → 합류지점 → 최종진입의 1~9번입니다. 웹 플레이는 원본 UE5 실행 검증을 대신하지 않습니다.

충돌·기믹 회귀 검사: `node tests/movement-check.mjs`, `node tests/fixtures-check.mjs`, `node tests/dungeon-state-check.mjs`. 실제 GLB의 필드 진입·순례자 계단 왕복·던전 변형 계단, 턱 높이 제한과 벽, 최종 문 두 파츠 및 충돌 해제, 중간보스 문 개방 후 생성과 초기화를 검사합니다.

사이트 디자인은 `css/game-theme.css`의 밝은 종이색·황동 테두리·명조 제목을 중심으로 관리합니다. 기존 도입 편지와 플레이 기능을 유지하며, 맵 썸네일은 본인 기획서에서 추출했습니다. 장식 이미지 출처는 `assets/images/SOURCES.md`에 기록했습니다.
